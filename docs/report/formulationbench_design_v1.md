## 3. 分层抽样方案(基于 1,945 全深度药的真实分布)

| 层 | 药数 | 抽样配额(300题)|
|---|---|---|
| BCS I(高溶高渗)| 647 | 60 |
| BCS III(高溶低渗)| 608 | 60 |
| BCS IV(低溶低渗)| 462 | 60 |
| BCS II(低溶高渗)| 58 ⚠ 预测规则偏松致低估 | 40(过采样,制剂最难层)|

### 3.2 按批准年代(反映数据时代与文献可得性)

## 4. 污染控制(四机制)

| 机制 | 实现 |
|---|---|
| ① 私有留出集 | 300 题按分层随机 70/30 切分;**私有 30% 不进任何公开文件**,论文主结果以私有集为准 |
| ② 合成药名探针 | 生成 ~20 个"真实性质+虚构名称"的合成药(性质取自真药、名称为无意义造词);模型若对合成药"答对",证明靠记忆名称而非推理 |
| ③ Canary 字符串 | 题目集嵌入唯一标识串;若出现在其他模型训练数据可追溯 |
| ④ DB 快照冻结 | 全部 ground truth 绑定 `data/drug_intelligence.local.db` 的 SHA256;论文附哈希与导出脚本 |

## 5. 模型 × 条件矩阵

- **模型(≥6)**:DeepSeek-V4-Pro、GPT-5.4 / mini、Claude(代理)、Qwen 或 Llama 开源权重(本地)、MiniMax-M3、一个小参数模型(成本轴)
- **条件(5)**:① 无工具 ② 通用 RAG(无溯源文本)③ DrugDB 工具(纯数值)④ DrugDB+溯源标注 ⑤ DrugDB+冲突注入(对抗)
- **重复**:每格 ≥3 次(temperature 0.1);报告 bootstrap 95% CI、配对 McNemar/Holm 校正
- **人类基线**:2 名制剂研究者回答 50 题子集;C/F 类报 Cohen's κ;LLM-judge 与专家重叠 20% 校准(ρ≥0.7 方可采用)
