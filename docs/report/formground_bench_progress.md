## 2. 试点已证明的(这是"能不能做出来"的实证答案)

1. **自动 ground truth 可行**:题目由 DB 生成,真值精确,判分零人工——规模化无人工瓶颈
2. **强信号存在**:42%→92%(+50pp)远超预设 15pp 门槛;实体混淆 33%→0%
3. **预注册机制有效**:H2 假设(模型过度自信)实测 0%,按预设规则当场 pivot——评审最看重的"科学过程严谨性"已被演示
4. **失败模式真实且可分类**:已捕获数值编造、盐型混淆、(D类判分待修)——失败分类学有素材
